# Desktop and Ranch

The floating dock is the everyday control panel. Use short mode for a compact launcher and long mode for readable task/bot controls. Drag its grip, resize the expanded panel, and pin it when useful.

| Area | Use |
| --- | --- |
| Bots | Start sessions, inspect status, ring for attention, admit/retire profiles |
| Board | Create tasks, assign/reorder queues, connect dependencies, release work |
| Factory | Create or edit saved profiles, roles, colors, and designs |
| Pipeyard | Read run progress, JSON responses, notes, and history |
| Ranch | Open the visual bots/animals/pipes view |
| AI Sync | Give local agents Inspect, Organize, or Operate access |

Settings and Full Board can open separate windows. Task assignment alone does not start work: release it for eligible pickup or explicitly Start. Unfinished dependencies block pickup. Family colors are stable labels; they do not determine task state.

Each task starts a fresh conversation with bounded, project-scoped continuity. Sticky families prefer a suitable bot familiar with the work without bypassing eligibility. Human-review tasks require a human decision.

Ranch taps and ordinary dragging are playful inspection. Explicit controls change work. The bell can wake sleeping residents, request work checks, call a Project Manager, or pause new pickup. Pausing pickup leaves current work running; offline/charging bots remain off.

Motion settings affect animation only. Menu-edge dead space remains available for iCUE gestures. Bot updates appear in the feed and brief speech bubbles; detailed task editing stays in the sidebar.
