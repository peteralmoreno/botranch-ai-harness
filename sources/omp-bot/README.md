# Ranch view

Observational bot activity, four work stations, playful movement, short updates, and an integrated Desk. A second page shows Pipeyard. Task/profile editing belongs in the desktop sidebar.

Use the standalone Ranch window or import the matching iCUE widget, allow localhost, and pair using the Settings connection key. See [installation](../../docs/guides/bot-ranch-install.md) and [desktop operation](../../docs/guides/bot-ranch-desktop.md).

Selecting or ordinarily dragging a bot does not interrupt work. Bell actions explicitly request wake/checks or pause future pickup. Offline bots remain off. Motion and theme choices affect presentation only. Missing runtime/model metadata stays marked unavailable.
